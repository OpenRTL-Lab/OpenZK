# 当前目录说明

[English](journal.en.md)

本目录索引 11 类 MIT 许可的独立硬件加速器，提供模块选型与链接，不含硬件 RTL 或端到端 ZK 证明器。

## 阅读方式

通过仓库 README 选择算法、数域和随包配置。各算子仓库分别提供自己的版本、原生接口、参考模型、复现说明和测量条件。

## 来源声明

原创文件具有组织、项目和许可声明；严格格式数据使用相邻许可伴随文件，第三方声明保留对应归属与许可。来源声明检查不执行硬件测试。

## 范围

验证、综合和集成限制以各算子及其文档中的配置为准。本目录没有硬件源码发布附件，也不提供整体系统验证结论。
