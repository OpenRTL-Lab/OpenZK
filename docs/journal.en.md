# Current catalogue reference

[简体中文](journal.md)

This catalogue indexes 11 standalone MIT-licensed hardware accelerator families. It contains module-selection guidance and links, not hardware RTL or an end-to-end ZK prover.

## Reading the catalogue

Use the repository README to select an algorithm, field and bundled configuration. Each linked accelerator repository supplies its own version, native interface, reference models, reproduction instructions and measurement conditions.

## Source notices

Original files carry organization, project and license notices. Strict-format data uses adjacent license companions; third-party notices retain their applicable ownership and terms. Source-notice checks do not execute hardware tests.

## Scope

Verification, synthesis and integration limits are specific to each linked accelerator and its documented configuration. The catalogue has no hardware release archive or shared system-level validation.
